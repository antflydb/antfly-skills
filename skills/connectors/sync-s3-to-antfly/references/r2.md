# Cloudflare R2 checklist

- Use the account S3 API endpoint ending in `r2.cloudflarestorage.com`.
- Use the bucket name separately from the prefix.
- Preserve spaces and case in an existing object prefix.
- Grant list-bucket scope and object-read scope only for required content.
- Do not use an R2 dashboard URL as the endpoint.
- Decide separately whether citations or previews need public/custom-domain URLs,
  short-lived signed URLs, or an authenticated application proxy.

For a private bucket, never place the secret key or permanent object credentials
in a browser-visible response.
